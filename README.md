# Food-site  
#### A platform that provides a free space for ordering food and drinks, 10/04/2025  
#### By **Daniel Kamanga**

## Description  
Food-site is an online platform designed to make fast food and drink delivery simple and accessible. The site connects users to both major and minor restaurants and hotels that offer delivery services. Users can place orders, track them in real time, and mark delivered goods, all from the comfort of their device.

Its primary goal is to provide the general public with a quick, convenient way to get meals without needing to physically visit a store or restaurant.

## Setup/Installation Requirements  
* Clone the repository or download the project files  
* Navigate to the project directory  
* Install Django and any other necessary dependencies  
* Set up the SQLite database (default setup with Django)  
* Configure secret tokens in your environment variables  
* Run the Django server using the standard command  
* Follow additional installation instructions as shown on the website  

Enjoy your meals and shop later!
